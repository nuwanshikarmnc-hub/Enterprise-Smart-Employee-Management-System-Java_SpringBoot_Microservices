# Smart Employee Management System (SEMS) -
**REST API Design and Implementation**

An enterprise microservices-based application developed to manage employee operations efficiently using Spring Boot and MySQL

##  Microservices Implemented
The system consists of four core microservices, each running on an independent port with its own database.
* **Employee Service : ** Manages employee registration, profiles, departments, and positions.
* **Attendance Service: ** Handles clock-in/clock-out tracking and attendance records.
* **Leave Service :** Processes leave requests, approvals, rejections, and balances.
* **Payroll Service :** Manages salary calculations, allowances (HRA, dearness), deductions, and payment status.

##  Technology Stack
* **Language:** Java
* **Framework:** Spring Boot
* **Database:** MySQL
* **ORM:** Spring Data JPA
* **API Testing:** Postman
* **Build Tool:** Maven
